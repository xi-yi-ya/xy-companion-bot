# QQ 外观与表情（v0.11.0）

入口：Bot 设置 → QQ 外观与表情。复用现有 NapCat 4.18.42 / OneBot 反向 WebSocket，不开放额外 HTTP 服务、不改上游源码、不安装另一套人格或记忆系统。

## 实现与默认权限

| 能力 | 默认 | 原生动作 |
| --- | --- | --- |
| 换 Bot 头像 | 由我批准，间隔 24 小时 | set_qq_avatar |
| 改 Bot 昵称 | 由我批准，间隔 24 小时 | set_qq_profile，仅 nickname |
| 改 Bot 签名 | 自主，间隔 12 小时 | set_self_longnick |
| 本地收录表情 | 自主 | 文件在 outbox，标签/来源/向量在 PG |
| 同步 QQ 收藏 | 自主 | add_custom_face，并读取 fetch_custom_face_detail 核对 MD5 |

五项都可独立关闭、先确认或自主执行。自动识别与 QQ 收藏各限每小时 4 次，图库容量默认 2000；可设置。头像接受 PNG/JPG，表情支持 PNG/JPG/GIF/WebP。Bot 不能通过聊天改这些开关。QQ 外观不会改 L0/L1，人设权限在修改审批页独立设置。

昵称/签名先做独立公开资料检查，拒绝泄露凭据或私聊信息。自动收录只处理 QQ 协议明确标记的表情，普通图不会自动进入队列；视觉分类为非表情或包含私人信息时必须手动确认。收到的图先存待审区，未批准时不能绕过收录工具直接发送。

## 工具与作用域

- 主人私聊：companion_qq_profile、companion_qq_customize、companion_qq_favorites、companion_sticker_collect。
- 当前会话：companion_sticker_search、companion_sticker_send；群内只能使用原群或明确共享的表情，发图还须具有群附件权限。Web 可以发到当前聊天或绑定主号 QQ，群内不能指挥跨会话发送。
- 素材 ID、参数、目标与实际 Bot 账号在执行层校验，模型不能提交任意磁盘路径。搜索结果带标签与描述；发送成功才累计使用次数，不强制每轮发表情。
- 图库管理支持预览、场景搜索、停用/启用、仅主人/共享范围切换，以及单独同步 QQ 收藏。停用不删除原文件与记录。

qq_custom_actions 保存候选、状态和原始消息来源；原生写操作另有 qq_operations 回执。唯一键与同步状态防止重复调用；发送结果未知时不自动补发。切换开关会在外部调用前再次检查，QQ 急停同样约束这些操作。已排队任务在服务重载后取消或标记未知，不在重启后偷偷补做。

QQ 收藏接口接受不等于列表已出现。界面和工具区分 sent 与 verified；真实 QQ 列表确认失败不宣称“已在收藏面板看到”，也不重复加入。头像/CDN 更新可能延迟，接口回执不等于手机端外观已刷新。

## 现成实现参考

核查本机 NapCat 原生处理器及[官方接口文档](https://napneko.github.io/onebot/api)。参考 [kai_presence](https://github.com/kumavulp/astrbot_plugin_kai_presence) 的资料 Function Tool 结构，以及 [meme_magpie](https://github.com/Whereis-Alice/astrbot_plugin_meme_magpie) 的收录、标注、检索流程。未复制其源码或安装整套插件，避免与现有人设、PG 和记忆生命周期重复。之前列出的 L1ke40oz 资料插件在本轮复查时返回 404，不作为部署依赖。

## 人设申请修复

QQ 的“那就都加、提出来”等承接式指令曾漏过识别，使文本工具草稿未入库。现在校验明确工具名称、参数、真实本轮用户来源和一致性；解释/示例/不要执行的文字不会当作申请。实际数据库回执决定待审或生效，不能由模型自行宣称成功。历史失败可按实际用户与助手消息恢复申请，不伪造来源。

修改审批增加 confirm/auto 和每天自动修改上限（默认 4，范围 1～20）。仅新候选可按 auto 生效；旧待审仍须手动处理。自动批准有 system_auto 与 auto_approve 留痕，版本冲突或配额不足保留待审并显示原因，检查失败不能通过自动模式绕过。L0 > L1 > L2、普通记忆衰减和每日整理规则不变。

## 回滚与验证边界

设置关闭相应能力或启用 QQ 急停即可停止后续动作。回退代码时保留新增表与历史，避免删除真实聊天或人格数据；不修改已发布的 QQ 资料，不自动删除 QQ 收藏。GUI/EXE 读取动态插件页面，本次无需重打包启动器。

隔离 PG 测试覆盖待审、自动执行、限额、去重、原生拒绝/未知结果、权限竞态、来源隔离和队列不循环。真实账号与浏览器验证结果以本轮执行记录为准，单元测试通过不代表真实头像已更换或手机端已刷新。
